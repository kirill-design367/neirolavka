## Что это за проект

«Нейролавка» — одностраничный лендинг, продажа аккаунтов с доступом к нейросетям
Claude и ChatGPT русскоязычной аудитории.

**Сайт ничего не обрабатывает.** Ни регистрации, ни оплаты, ни личного кабинета.
Человек выбирает нейросеть и тариф, панель заказа собирает выбранное, кнопка уводит
в Telegram-бот. Регистрация по номеру, оплата, выдача доступа и реферальная система
живут в боте — он пишется отдельным этапом.

Задача страницы одна: чтобы человек поверил, что его не кинут, и увидел, что покупка
занимает две минуты.

## Команды

```bash
npm run dev                       # разработка
npm run build                     # статический экспорт в out/
npx tsc --noEmit                  # проверка типов
python3 scripts/subset-fonts.py   # перенарезать шрифты (нужен fonttools+brotli+uharfbuzz)
```

Проверки. Сначала поднять выдачу: `npm run build` и отдать `out/`
статикой на `localhost:4173` (сервер должен **сжимать**, иначе замер
производительности занижен — GitHub Pages сжимает).

```bash
node scripts/check-export.mjs out /neirolavka   # выдача: basePath, .nojekyll, preload
node scripts/verify-live.mjs   <url>            # запросы, консоль, CLS
node scripts/check-contrast.mjs <url>           # контраст на отрисованной странице, обе темы
node scripts/check-theme-motion.mjs <url>       # вспышка темы, prefers-reduced-motion
node scripts/measure-fps.mjs <url> [замедление] # кадры на настоящей прокрутке
node scripts/lighthouse-median.mjs <url> 10     # медиана десяти прогонов
node scripts/screenshots.mjs <папка> <url>      # три разрешения × две темы
python3 scripts/audit-fonts.py <папка с ttf>    # cmap и покрытие кириллицы
python3 scripts/audit-kerning.py <папка с ttf>  # кириллические кернинг-пары
```

`NEXT_PUBLIC_BASE_PATH` — префикс пути. На GitHub Pages `/neirolavka`, на своём
домене оставить пустым.

## Стек

Next.js App Router (статический экспорт, `output: 'export'`), TypeScript, Tailwind 4
(CSS-first, `@theme inline`), GSAP + ScrollTrigger, Lenis. Three.js не используется:
всё нужное движение достижимо на CSS и GSAP, а он стоил бы плавности.

### Каталог

Компоненты обращаются к каталогу **только** через `getCatalog()` из
`src/lib/catalog.ts`. Когда каталог поедет из бота по API, меняется тело этой
функции — типы и компоненты остаются нетронутыми. Не импортировать данные напрямую
в обход неё.

Цены сейчас у всех тарифов **1 ₽**: настоящего прайса ещё нет.

### Темы

Две: светлая (тёплый камень `#f2eee7`) по умолчанию и тёмная (глубокий графит
`#191c1a`). Ни чистого белого, ни чистого чёрного.

Вспышка при загрузке решена так: `themeInitScript` из `src/lib/theme.ts` встроен
синхронным `<script>` в `<head>` и ставит `data-theme` на `<html>` **до первой
отрисовки**. Выбор хранится в `localStorage`.

Плавность перехода даёт класс `.theme-transition`, который вешается на `<html>`
только на время переключения и снимается через 320 мс — иначе каждый ховер тоже
перекрашивался бы с задержкой.

**Любая новая пара текст/фон проверяется на 4.5:1** через `scripts/contrast.py`.

### Типографика

Ровно **пять ступеней кегля**, больше заводить нельзя: `--t-display`, `--t-title`,
`--t-body`, `--t-label`, `--t-micro`. Цена набирается существующей ступенью с
классом `.tnum` (табличные цифры), а не новой ступенью.

Гарнитуры: **Akt** (Дмитрий Гренев) дисплейная, **Golos Text** (Александра
Королькова, Виталий Кузьмин, ParaType) текстовая. Обе с настоящей, а не формально
дорисованной кириллицей — проверено по таблице cmap в бинарнике. Третий вариант,
**Onest**, показан на `/fonts` и подключается только там.

### Движение

GSAP поверх Lenis, **один такт через тикер** — отдельного `requestAnimationFrame`
для Lenis быть не должно, иначе два цикла разъезжаются и появляется дрожание.
Lenis поднимается в layout-эффекте, а не по `window.load`.

Правила:
- Появление блоков по прокрутке: проявление плюс лёгкий масштаб, 0.8–1.0 с,
  `power2.out`, stagger 0.06–0.08.
- **Текст никогда не масштабируется** — браузер растягивает готовый растр и буквы
  размываются. Масштабируется только контейнер, текст внутри — отдельным слоем
  без `scale`.
- Наведение: только `transform` и `opacity`.
- `prefers-reduced-motion` уважается: Lenis не поднимается, появления
  превращаются в мгновенную установку конечного состояния.

## Правила, которые легко нарушить

- Не добавлять авторизацию, регистрацию, оплату и личный кабинет на сайт.
- Не собирать персональные данные.
- Не ставить стоковых изображений и не генерировать картинки.
- **Латиница только в именах брендов** (Claude, ChatGPT, Telegram, USDT, СБП)
  и в именах переменных. Весь интерфейсный текст — по-русски.
- Не заводить шестую ступень кегля.
- Композиция не должна превращаться в ленту одинаковых секций.

Мобильная — отдельная композиция, а не сжатый десктоп.

## Публикация

`.github/workflows/deploy.yml` собирает статический экспорт, проверяет выдачу
скриптом `check-export.mjs` и публикует **двумя путями**:

1. `deploy-artefakt` — штатный `actions/deploy-pages`, работает, когда
   источником Pages выбрано «GitHub Actions». Помечен `continue-on-error`.
2. `deploy-vetka` — та же выдача уезжает в ветку `gh-pages`. Окружение
   `github-pages` не задействуется вовсе, поэтому этот путь работает всегда.

Почему так: задача с окружением `github-pages` падает мгновенно, ещё до
первого шага, — окружение не пускает эту ветку. Настройки Pages из этой
среды недоступны (API закрыт прокси), поэтому вместо починки настроек
добавлен путь, который от них не зависит.

`.nojekyll` создаётся в корне выдачи на шаге сборки, иначе Pages выбрасывает
папку `_next`.

**Чтобы сайт открылся,** нужно один раз выбрать источник в настройках
репозитория: Settings → Pages → Build and deployment → Source →
«Deploy from a branch» → ветка `gh-pages`, папка `/ (root)`.

Ветка разработки: `claude/neirolavka-site-setup-bd3e7p`.
